LLM Council Verdict

Separate estimation from gripper selection

Should Gecko and silicone forces come from one non-comparative joint VLM call, or two isolated calls when Python makes the final choice?

Use two isolated per-gripper calls, execute them concurrently, and keep all comparison and selection logic in deterministic Python.

Why

Removing recommendation fields does not remove contextual coupling. A joint prompt still exposes each estimate to the other embodiment, evidence set, and output slot.

Temperature zero improves repeatability; it does not guarantee noninterference.

Implementation contract

  • One canonical per-gripper prompt and schema.
  • Only one embodiment and its evidence per call.
  • No winner, recommendation, comparison, or competition framing.
  • Parallel calls with independent cache, retry, and timeout.

Chairman's synthesis

Where the council agrees

Two isolated calls are the scientifically cleaner default. The VLM returns force and feasibility only; Python remains the sole selector. Parallel execution and independent caching reduce the latency and recomputation penalty.

Where the council clashes

The only disagreement is whether a joint call could later be accepted after an equivalence-bounded ablation. The final verdict keeps joint mode only as an explicitly labeled experiment, not as the primary scientific pipeline.

Blind spots caught in peer review

Isolation gives noninterference, not automatic validity. Both calls still share model and dataset biases. Freeze the model, prompt, schema, image preprocessing, retrieval index, evidence order, units, physical force definition, retries, and selector version. Validate each gripper against held-out ground truth and never silently select from one successful call if the other failed.

Advisor views

The Contrarian

A joint call remains structurally coupled even without comparison wording. The extra call cost is justified to remove an avoidable scientific confound.

The First Principles Thinker

The estimand is per-gripper absolute force. Use matched isolated calls, per-gripper calibration, and a fully specified Python policy for ties and failures.

The Expansionist

Separate calls create a cleaner production system and a useful ablation surface. Preserve exact provenance and quantify joint-versus-separated drift.

The Outsider

The hidden requirement is invariance: enabling silicone must not change Gecko's prediction. Avoid even implicit competition framing.

The Executor

Build one canonical function, invoke it twice concurrently, and isolate caching, retries, and failures per gripper.

Peer-review highlights

Reviewers emphasized correlated model errors, held-out calibration, frozen retrieval evidence, precise force definitions, provider version drift, timeouts, retry symmetry, and an explicit incomplete state.
